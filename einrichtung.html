2 · Schritte für dein Gerät (steps for your device)

📱 Android

🔊 Deutsche Stimme (German voice)
  1. Open Settings → System → Languages & input → Text-to-speech output (on some phones: Settings → Accessibility).
  2. Preferred engine: Speech Services by Google. Tap the ⚙ gear next to it.
  3. Tap Install voice data → Deutsch (Deutschland) and download it.
  4. Come back here and press Anhören above. Turn the media volume up.
🎙 Mikrofon (microphone)
  1. Use Chrome. Press Testen above and tap Allow when asked.
  2. If you tapped Block: tap the 🔒 icon (or ⋮ menu → Settings → Site settings → Microphone) and set this site to Allow.
  3. Still silent? Settings → Apps → Chrome → Permissions → Microphone → Allow.

📱 iPhone / iPad

🔊 Deutsche Stimme (German voice)
  1. Open Settings → Accessibility → Spoken Content. Can't find it? Pull down in Settings and search for Spoken Content, or scroll the Accessibility list (it is in the Vision group).
  2. Turn on Speak Selection (or Speak Screen). The Voices row only shows up after that. You don't have to use the feature.
  3. Tap Voices → German, pick a voice (for example Anna) and tap the download icon. Enhanced sounds best. Use Wi-Fi.
  4. Still no German in the list? Try Settings → Accessibility → VoiceOver → Speech → Add New Language → German, or add German in Settings → General → Language & Region → Add Language first.
  5. Check the silent switch on the side: if it is on (orange), the sound stays off. Turn the volume up.
  6. Come back here and press Anhören above.
🎙 Mikrofon (microphone)
  1. Use Safari. Press Testen above and tap Allow.
  2. If you tapped Don't Allow: tap aA in the address bar → Website Settings → Microphone → Allow.
  3. Or: Settings → Apps → Safari → Microphone → Ask / Allow.
  4. Recording does not work in some in-app browsers (inside other apps). Open the page in Safari.

💻 Windows

🔊 Deutsche Stimme (German voice)
  1. Edge has the best voices (for example Katja, Conrad, "Online (Natural)"). Chrome also works with "Google Deutsch".
  2. No German voice in the test? Open Settings → Time & language → Speech → Manage voices → Add voices and add German (Germany).
  3. Restart the browser, then press Anhören above.
  4. Pick a voice with the small voice menu in the page header, if you see one.
🎙 Mikrofon (microphone)
  1. Press Testen above and click Allow in the pop-up.
  2. If you clicked Block: click the 🔒 icon left of the address → Microphone → Allow, then reload.
  3. Still silent? Settings → Privacy & security → Microphone: turn on Microphone access and Let desktop apps access your microphone.
  4. Check the right microphone is chosen in Settings → System → Sound → Input.

💻 Mac

🔊 Deutsche Stimme (German voice)
  1. Open System Settings → Accessibility → Spoken Content.
  2. Click System voice → Manage Voices… → German and download Anna (or Markus, Petra). Enhanced / Premium voices sound better.
  3. Restart the browser, then press Anhören above.
  4. Chrome also brings its own "Google Deutsch" voice.
🎙 Mikrofon (microphone)
  1. Press Testen above and click Allow.
  2. Safari: Safari menu → Settings → Websites → Microphone → set this site to Allow.
  3. Chrome / Edge / Firefox: click the 🔒 icon left of the address → Microphone → Allow, then reload.
  4. Still silent? System Settings → Privacy & Security → Microphone → turn your browser on.

🖥 Linux / Chromebook / other

🔊 Deutsche Stimme (German voice)
  1. Chrome and Chromium usually bring online "Google Deutsch" voices. You need an internet connection.
  2. Firefox on Linux: install speech-dispatcher and a German voice (for example espeak-ng or mbrola-de), then restart Firefox.
  3. Chromebook: Settings → Accessibility → Text-to-speech → Voices: add German.
🎙 Mikrofon (microphone)
  1. Press Testen above and click Allow.
  2. If blocked: click the 🔒 icon left of the address → Microphone → Allow, then reload.
  3. Check the input device in your system sound settings.
Reminder · Why no sound? Four common reasons: the volume is off (phones: media volume), the silent switch is on (iPhone), there is no German voice installed, or the page is opened inside another app. The microphone also needs https (or a local file on your own computer). The page works without a voice: you still see everything, you just don't hear it.
